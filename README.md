# URSE Standards

Standards published by the URSETek organization.

The public site is at <https://ursetek.github.io/standards/>.

## Adding a standard

1. Create `standards/<id>/index.html`.
2. Link the shared stylesheet: `<link rel="stylesheet" href="../../assets/style.css">`.
3. Add a row to the table in `standards/index.html`.
4. If the standard deserves a place on the home page, add a card to `index.html`.
