About

Statuses

Every standard carries one of the following statuses:

Status Meaning
Provisional The standard is published, but not yet ratified by an RFC.
Consolidated The standard is ratified by one or more RFCs. The standard page lists them under Consolidated by.
Deprecated The standard is no longer recommended, but no replacement exists.
Superseded The standard has been replaced by a later one.

Consolidation

A standard begins as Provisional: the text exists, but it has not been ratified by the RFC process. When the URSETek RFC process is running, one or more RFCs are written in the URSETek/rfcs repository. Once those RFCs are accepted, the standard moves to Consolidated and its page gains a Consolidated by section listing the RFCs that back it.

A provisional standard MAY use the IETF RFC 2119 keywords (MUST, SHOULD, MAY), but is not required to. A consolidated standard MUST reference the RFCs that ratify it.
